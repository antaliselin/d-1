## 0　摘要

**这段要回答**：这个系统在整局里负责什么，不负责什么，谁依赖它。

### 0.1　一句话职责

让玩家把手下的幸存者**派出去**：选重点类别、给预算、塞装备，第二天他们带着一袋货回来——**不占当天**。

### 0.2　不做什么

| 不做                   | 谁做                 |
| ---------------------- | -------------------- |
| 不决定仓库里有什么     | S02 物品与库存       |
| 不算这些东西值多少钱   | S05 结算             |
| 不决定谁可以被雇佣     | S04（客人与特殊客人）|
| 不画派遣面板           | 客户端表现           |

### 0.3　依赖

- 上游：S02（物品表、库存扣减）、S04（声望：影响装备归还率）。
- 下游：S02（战利品入库、装备归还）、S06（共用"一趟带回多少件"的口径）。

### 0.4　验收标准

一句话：**派出去的人第二天一定回来，带回来的东西在 15~45 件之间，投放的武器要么还回来、要么明确损失。**

可测三条：

1. 每趟产量落在 15~45 件。
2. 投放的枪械/近战要么进 `returned`、要么进 `lost`，不会有第三种结果。
3. 医疗用品永远不归还（消耗品）。

## 2　规则

**这段要回答**：配置怎么算成产量、装备怎么算成加成、回来时怎么结算。

### 2.1　谁能派

- 每位**在家的**拾荒者每天最多派一趟；已经出门的不能重复派。
- 派遣**不占当天**：派出去的同时照常营业。
- 出发当天照常过，第二天早上（收租之后）弹归来日志。

### 2.2　配置

```text
类别：0~3 个，可多选；不选 = 所有类别等权
预算：50~500，步进 50
装备：最多远程 1 件 + 近战 1 件 + 医疗 1 件
```

装备会**从库存里扣掉**（S02 的取出口径），归来时按 2.6 决定还不还。

### 2.3　产量

```text
收益率 = 1 + 预算占比 × 0.25 + 装备加成
    预算占比 = min(1, 预算 / 500)
    装备加成 = min(0.45, 各件加成之和)

产量 = clamp( 随机(15, 30) × 收益率, 15, 45 )
```

- 满预算 = +0.25，装备拉满 = +0.45，理论上限 1.7 倍。
- 下限 15、上限 45 是硬约束，收益率再高也不会超过。

### 2.4　抽什么

```text
每个"件"从加权池里抽一次，重复 target 次：
    权重 = 价值档 × 类别倍数 × 枪械折减
        价值档：≤40 瓶盖 0.85；≤150 0.6；更贵 0.4
        类别倍数：选中类别 ×4，其它 ×1；不选时全部 ×1
        枪械折减：枪械 ×0.5
单件上限：枪 2 / 近战 2 / 弹药 6 / 奢侈品 3 / 工具 4 / 其它不限
```

三个设计意图：

- **贵的难抽**（0.4 档）：不让一趟直接搬回一堆高价值货。
- **枪械额外折减**：枪是稀缺品，派遣不能变成刷枪机器。
- **类别只改权重、不改数量**：选"医疗"是提高医疗占比，不是少拿东西。

**物品池 = 全部物品定义**，与货架、需求池保持一致（含合成产物）。

### 2.5　栽跟头

```text
概率 18%
命中后：丢掉 (当前件数 − 15) × (0.3~0.5) 件，从后往前丢
```

同样保住 15 件的下限：栽了跟头也不至于空手回来。

### 2.6　装备归还

```text
归还概率 = clamp(0.55 + 声望 × 0.002 − (栽跟头 ? 0.2 : 0), 0.1, 0.95)

枪械 / 近战：按概率归还 → 进 returned，否则进 lost
医疗用品：永远不归还（用掉了），记一条"用掉了"的日志
```

- 声望越高越靠谱：50 声望时约 65%，100 时约 75%。
- 装备的加成只在**出发这一刻**结算，丢了也不影响已带回来的货。

### 2.7　装备加成

```text
枪械：min(0.25, max(0.08, 价值 / 1100))   但必须有同口径弹药
近战：min(0.20, max(0.05, 价值 / 1200))
医疗：min(0.12, max(0.02, 价值 / 1800))

每一类只算第一件；三类相加后封顶 0.45
```

**同口径**：枪的 `tags` 与弹的 `tags` 里有同一个口径标签。没带配套子弹的枪，加成为 0（不是减半，是直接归零）。

### 2.8　归来

```text
第二天早上（收租之后）
   ↓ 播日志：翻到什么 / 丢了什么 / 装备还不还
   ↓ 战利品入库（弹药按发）
   ↓ 归还的装备回到库存
   ↓ 拾荒者回到"在家"状态，可以再派
```

## 3　状态与流程

**这段要回答**：一趟派遣经历什么。

### 3.1　时序

```text
点「派遣拾荒者」
   ↓ 选人（在家的才有）
   ↓ 选重点类别（0~3）
   ↓ 拉预算（50~500，步进 50）
   ↓ 塞装备（远程 / 近战 / 医疗 各 1）→ 立刻从库存扣掉
   ↓ 确认出发：写入这是第几天出发
   ↓ 当天照常营业
第二天早上：收租 → 归来日志 → 入库 / 归还 / 损失
```

### 3.2　与其它系统的接口

| 本系统消费 | 来自 | 用途 |
| --- | --- | --- |
| `ItemDef`（`value` / `tags` / `rounds`） | S02 | 抽池、加成、入库折算 |
| 库存 | S02 | 扣装备、加战利品 |
| 声望 | S04 | 装备归还率 |

| 本系统产出 | 给谁 | 用途 |
| --- | --- | --- |
| `gained` / `returned` / `lost` | S02 | 写库存 |
| `log` | 客户端 | 归来日志 |

## 4　交互与表现

**这段要回答**：玩家怎么配置、怎么看结果。

### 4.1　派遣面板

| 区域 | 规则 |
| --- | --- |
| 选人 | 在家的可点，已出门的置灰 |
| 类别 | 可多选 0~3 个，超出上限时最早的自动取消 |
| 预算 | 滑杆或加减，步进 50 |
| 装备位 | 三个槽位，只能放对应类别；放上去立刻显示加成 |
| 预估 | 面板上显示"预计带回 15~XX 件"（只显示区间，不显示具体值） |

### 4.2　归来日志

和搜刮同一套逐条播放的样式：翻到 → 正文色；丢了 → 暗红；装备没回来 → 暗红并标出名字。

## 5　边界与异常

| # | 情况 | 期望行为 |
| --- | --- | --- |
| 1 | 家里没有拾荒者 | 不显示派遣入口 |
| 2 | 所有人都在外面 | 入口可见但不可点，提示"人都在外面" |
| 3 | 预算超出 50~500 | 夹到区间内，按 50 取整 |
| 4 | 选了 4 个类别 | 只保留前 3 个 |
| 5 | 装备槽放错类别 | 拒绝放置，提示该槽只收什么 |
| 6 | 没带子弹的枪 | 枪械加成按 0 算，面板上明确提示"缺配套弹药" |
| 7 | 装备在出发后被别的操作消耗 | 不可能：出发即从库存扣走 |
| 8 | 栽跟头 + 只剩 15 件 | 不再丢货，只播日志 |
| 9 | 声望 0 / 100 | 归还率分别是 55% 与 75%（栽跟头再 −20%） |
| 10 | 第二天先收租后归来 | 顺序固定：收租在前，归来在后 |

## 6　验收用例

| # | Given | When | Then |
| --- | --- | --- | --- |
| 1 | 预算 500、不带装备 | 出发 | 收益率 1.25，产量在 19~38 之间（且夹在 15~45） |
| 2 | 预算 50、不带装备 | 出发 | 收益率 1.025，产量在 15~31 之间 |
| 3 | 带一把步枪 + 同口径弹夹 | 出发 | 枪械加成生效，计入 0.45 封顶 |
| 4 | 带一把步枪、不带弹 | 出发 | 枪械加成为 0 |
| 5 | 选"医疗"为重点 | 出发 | 医疗占比明显上升，件数不变 |
| 6 | 栽跟头（18%） | 归来 | 丢掉一部分，但不少于 15 件 |
| 7 | 投放近战武器 | 归来 | 要么在 `returned`，要么在 `lost` |
| 8 | 投放医疗用品 | 归来 | 永远不归还，日志写"用掉了" |
| 9 | 派出一位拾荒者 | 同一天再打开面板 | 该人置灰，不能重复派 |
| 10 | 第二天收租 | 归来日志 | 收租面板先出现，归来的在后面 |
